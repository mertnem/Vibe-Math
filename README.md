# Vibe Computing for Mathematicians

### Explore Mathematics with AI

**George Grätzer**

This repository contains the companions of the book *Vibe Computing for Mathematicians*.

The book is about mathematical exploration. It shows how a mathematician can use 
conversation with an AI system and small computer programs to investigate examples, 
test conjectures, find counterexamples, and develop explanations. 
The computer can extend a calculation or search; 
the reader must still decide what the result establishes 
and supply a proof when one is needed. 
No prior knowledge of Python is required to follow the main text.
The main text treats Python as optional. 

The Python Companion collects the programs for readers who want to run, 
adapt, or study them.

The Exercise Companion is in two parts. 
The first part gives hints to all exercises, and the second part gives complete solutions.
